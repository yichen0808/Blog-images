# Blog-images

「弈辰小筑」的图床仓库。所有文章配图、封面、图标都放在 `images/` 下，
由 [jsDelivr](https://www.jsdelivr.com/) 免费 CDN 分发。

## 链接格式

```text
https://cdn.jsdelivr.net/gh/yichen0808/Blog-images@main/images/<文件名>
```

三段分别是：`gh` 表示后面接 GitHub 仓库，`@main` 指定分支，最后是仓库内路径。

**`@main` 不能省。** 不带分支的链接会命中一份很早以前的缓存，刚推上去的图
可能半天刷不出来。同理，**改图请直接换文件名**——用同名文件覆盖，
访问到的很可能还是旧的那张。

## 目录约定

| 前缀 | 用途 | 建议尺寸 |
| --- | --- | --- |
| `avatar` | 头像 | 560×560 |
| `hero-bg` | 首页背景 | 2000×1125 |
| `photo-01…` | 拾光集照片墙 | 长边 1600 以内 |
| `cover-*` | 弦歌台曲目封面 | 800×800 |
| `book-*` | 话本斋书封 | 500×700（5:7） |
| `icon-*` | 格物斋链接图标 | 24×24 SVG |
| `og-cover` | 分享预览图 | 1200×630 |

## 上传纪律

**先压再传。** 原图动辄五到十兆，而站上用到的最大宽度也就两千像素。
照片一律导出 JPEG（`quality=82`、`optimize`、`progressive`），
只有需要透明通道的图标才留给 PNG 或者直接上 SVG。

单个文件控制在 400 KB 以内（首页背景放宽到 600 KB）。
这条纪律决定了三年后这个仓库是两百兆还是两个 G——
CDN 只负责送得快，不负责让文件变小。

## 为什么单独开一个仓库

图床仓库是**公开**的，源码仓库（`YC_Blog`）是**私有**的。

文章里的图片本来就要被所有人看到，公开它没有任何损失；
但源码目录里躺着草稿和没写完的想法，那些不适合被搜到。
分开之后，图片库的提交历史也很干净，清一色是「加了哪张、删了哪张」，
不会和文章改动混在一起。
